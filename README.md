# Rudersdorf 2 · Das Labyrinth

**Lukis Python-Werkstatt, Teil 2.** Die Orks kommen zurück, und diesmal gibt es keinen festen
Weg mehr: Du baust deine Türme frei auf ein Raster, und die Orks suchen sich ihren Weg durch
dein Labyrinth. Dazu kommen ein Dorf, das du ausbaust, eine Kirche, die zur gotischen
Kathedrale wächst, und Zauber.

Dieses Spiel ist der Nachfolger von [Rudersdorf](https://github.com/konih/rudersdorf).

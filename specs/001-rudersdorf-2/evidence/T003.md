  Written now, because a guard may only become stricter later (constitution, *Quality gates*).

  mission 12.

- **`tests/architektur/quelltext.py`** holds the four `ast` helpers both guards use. Its name

  first "registry knows all unsolved missions" test filtered the registry by the list itself and
  could not fail. Recorded in `loop.md` *Lessons*.

  workshop lacks, so reference helpers start with an underscore (or are inner functions);

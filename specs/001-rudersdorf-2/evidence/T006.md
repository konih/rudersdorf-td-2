## Decisions taken inside the task

- **Mission tests call the package directly, not through the workbench.** `helfer.lade_modul`
  imports `<paket>.<modul>` with `rudersdorf.werkbank.waehle_paket()`; a `NochOffen` therefore
  reaches the runner as it is and the runner (T019) can report "still open".
- **Message helpers.** `helfer.Missionstest` (base class, `longMessage = False`) offers
  `pruefe_gleich`, `pruefe_fehler`, `rufe_sicher`, `pruefe_unveraendert` and `pruefe_abstaende`.
  Every failure text comes from `helfer.meldung(erwartet, bekommen, tipp)`. `rufe_sicher` turns
  a crash of learner code into the same three-part message where the crash is the expected
  mistake (an `IndexError` for a cell outside the grid); the original traceback stays attached.
  `NochOffen` is never caught.
- **Maps are drawn as text** (`helfer.raster_aus`, `helfer.abstaende_aus`), so tests from mission
  2 on do not depend on the learner's `lies_karte`.
- **`tests/missionen/test_helfer.py`** is not named by the task. The helpers do not run in the
  repository while every mission raises `NochOffen`, so without it the three-part message would
  have no sensor until T007.
- **Stand-in shapes** follow `rudersdorf/ersatz.py` (capability → the workshop's name → callable
  with the workshop's arguments) and are fetched with `ersatz_fuer`, as the workbench does.
  What the tests fix for T007:
  - `karten`: `lies_karte(text)` ignores the text and returns a fresh grid of `flusstal`, equal to
    `karten/flusstal.txt`; `finde` works on that grid. This is the one reading of "only the
    built-in map `flusstal` can be chosen" that the registry can express.
  - `wegfindung`: `abstandskarte` maps every cell of the grid, rock and buildings included, to its
    Manhattan distance; following `naechster_schritt` on that map walks straight through a wall.
  - `bauregel`: `darf_bauen` is false for the eight cells around a cell in `gesperrt`, true with
    one cell between or with no building.
- **Not asserted, because the spec set leaves it open:** what the `karten` stand-in does with a
  broken text; whether the `bauregel` stand-in checks terrain, the grid border or `besetzt`
  (FR-004 and the engine's safety net cover placement); the stand-ins `nachbarn` and
  `ist_begehbar` beyond existing;
  returning exactly `bool` rather than a value equal to `True` or `False` in missions 2 and 5.

## Learnings

Class: guidance (all three persisted as lines in loop.md, *Lessons*).

- Test code that inspects a learner's answer before comparing it (sorting it, indexing it) must
  survive any answer; put that logic in a helper with its own test for `None` and mixed lists.
- A case left out "because the hint would confuse" is still a contract rule: reviewer A finds it.
  Write the case and a plain hint.
- After the mutant run, list the tests no mutant turned red: it showed one test implied by
  another rule (kept, proven red by a combined mutant) and one mutant still missing.

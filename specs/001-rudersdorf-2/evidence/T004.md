## Decisions taken inside the task

- **Stand-in registry.** `rudersdorf/ersatz.py` holds one dictionary, `ERSATZ`: capability →
  name → function or class, the name being the workshop's. The workbench looks an entry up at
  every call and never copies the dictionary; constructing a workbench and probing need no
  entry; a class stand-in is constructed with the original's arguments. A test registers its own
  entries with `unittest.mock.patch.dict(ERSATZ, {...}, clear=True)`. This is the shape T005's
  text names ("a dictionary capability → name → callable or class"); the stub's docstring states
  the four rules.
- **Temporary packages.** `Probepaket` writes every module and name of the registry as "solved"
  (functions accept anything and return `None`; classes accept anything and answer every
  method), then replaces single names with the test's own source. So a package is solved under
  any probe input T005 chooses, and the hand-written parts carry the contract's signatures. Each
  package has its own name (`wb_probe_<pid>_<n>`) and its own temp directory; a cleanup removes
  the path entry, the modules and the directory.
- **File times.** Every write moves the file's modification time on by ten seconds. Without it
  an edit inside the same second and of the same length is served from the byte-code cache, which
  would make the reload tests fail for a reason that is not the workbench's.
- **Late `NochOffen`.** Besides the task's case (a function that raises `NochOffen`, which the
  probe already sees), two tests raise `NochOffen` only for an input no probe uses (`art ==
  "spaet"`, `sekunden == 777`). They are the only tests that reach "on `NochOffen` it marks the
  capability open" in `rufe` and in the wrapped instance (plan.md, *Fixed engine interfaces*).
- **`Lernfehler.datei`** is checked by its end (`<paket>/horde.py`), so an absolute and a
  package-relative path both pass; the spec set does not fix which.
- **Not asserted, because the spec set leaves it open:** what an object created before its
  capability opened answers afterwards (M38); what `wartet_auf` returns for a capability that is
  open by itself and also has an open prerequisite (M27); `waehle_paket(False)` with the
  variable set to `1`; the location fields of the `Lernfehler` a syntax error raises;
  `strategien()` (its behaviour belongs to T012's story); a missing stand-in entry.

## Learnings

Class: guidance (recorded in loop.md, *Lessons*).

- A table handed to learner code must be valid under the contract's own rule for that code: test
  the real table with the contract's rule written out in the test, not only its keys.
- A faulty-copy self-test should change a value nothing else refers to; otherwise the checker
  rightly reports two errors and the case, not the checker, is wrong.
- A cycle self-test needs one cycle that exists only through the implicit "level before" edge;
  direct cycles leave that edge unproved.
